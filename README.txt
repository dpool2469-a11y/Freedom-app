FREEDOM Finance — GitHub Pages upload
1. Download and extract FREEDOM-ready-GitHub.zip.
2. In your GitHub repository, upload/replace these files in the repository ROOT:
   index.html, style.css, script.js, manifest.json, service-worker.js
   and the icons folder (with icon-192.png and icon-512.png).
3. Commit the changes.
4. Open https://dpool2469-a11y.github.io/Freedom-app/
5. If old styles remain, open the site in a new browser tab and refresh. Do NOT clear site storage; it may contain your financial records.
Data is stored in this browser's localStorage and is not encrypted. Export a backup in Settings before making major changes.
